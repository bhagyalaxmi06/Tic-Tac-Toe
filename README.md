# 🎮 Tic Tac Toe Game (Web Project)

A fun and interactive **Tic Tac Toe game** built using **HTML, CSS, and JavaScript** with creative UI, sound effects, and AI gameplay.

---

## ✨ Features

* 🎨 **Creative UI Design**

  * Background images for each page
  * Kids-themed welcome screen
* 🔐 **Login System (Frontend)**

  * Username & password input
* ❌⭕ **Choose Your Symbol**

  * Player selects X or O manually
* 🤖 **Single Player Mode**

  * Play against AI
* 🎯 **Winning Detection**

  * Highlights winning cells
  * Winning line animation
* 🔊 **Sound Effects**

  * Click sound
  * Win / Lose sound
* 🔁 **Restart Game**

  * Reset board instantly
* 💾 **Local Storage**

  * Saves player choice

## 🚀 How to Run

1. Download or clone the repository
2. Open the folder in **VS Code**
3. Install extension: **Live Server**
4. Right-click `welcome.html`
5. Click **"Open with Live Server"**
